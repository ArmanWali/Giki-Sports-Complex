# GIKI Sports Complex Management System

A web-based system for viewing sports facility timings and rules, booking Padel courts, managing gym memberships and payments, and displaying GIKI’s sports achievements.

This project is being developed for **SE423 — Software Construction and Development** and **SE431 — Software Quality Assurance**.

Code development has recently started. Setup and installation instructions will be added once the initial application structure is ready to run.
